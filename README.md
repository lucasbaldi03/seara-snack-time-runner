# Seara Snack Time Runner

Jogo web em HTML5 Canvas, preparado para publicação online na Vercel.

## Como jogar

Abra o link publicado, clique ou toque na tela para iniciar e use os controles exibidos pelo próprio jogo.

## Execução local

O projeto é estático. Basta servir esta pasta com um servidor HTTP local e abrir `index.html` no navegador.
